# 坦克大战 · Tank Battle

一个使用 **HTML5 Canvas** 编写的经典坦克大战网页游戏。单文件、零依赖，打开即玩。

## 特性

- 🎮 经典玩法：驾驶坦克击毁敌军，保卫底部基地
- 🧱 可破坏的砖墙、不可破坏的钢墙、阻挡坦克的水域、可藏身的草丛
- 🎯 4 种敌军（普通 / 快速 / 装甲 / 重装），随关卡增强
- ⭐ 5 种补给：火力升级、护盾、额外生命、冻结敌军、全屏轰炸
- 🗺️ 4 个精心设计的关卡，通关后显示胜利
- 🔊 实时音效（Web Audio 合成，无需音频文件）
- 📱 支持触屏按键，手机也能玩
- 💾 本地记录最高分

## 操作

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` | 射击 |
| `P` | 暂停 |
| `回车` | 开始 / 继续 |

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖或服务器。

也可以本地起一个静态服务：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 在线试玩

将本仓库部署到 GitHub Pages 后，即可在线游玩（Settings → Pages → 选择分支保存）。

## 游戏规则

- 击毁所有敌军即可过关
- 基地（底部中央的鹰形徽章）一旦被击毁，游戏立即结束——注意别打到自己家的基地
- 击毁敌军有机会掉落补给，驾驶坦克碾过即可拾取
- 玩家阵亡后火力等级会重置

## 技术说明

- 纯前端单文件实现，无外部依赖
- 使用 `requestAnimationFrame` + 基于时间步长的游戏循环
- 分轴碰撞检测，支持贴墙滑动
- 原创 Canvas 矢量绘制（坦克、鹰形基地、砖墙、水域动画等）
